# AI Job Application

This repository contains the reusable **JobHuntBot** Codex skill.

The skill supports a structured job-search workflow covering candidate setup,
job screening, resume routing and tailoring, application assistance, explicit
submission approval, tracking, blockers, and follow-up.

## Skill location

`skills/jobhuntbot/SKILL.md`

When installing from this repository, select `skills/jobhuntbot` as the skill
directory.

## Privacy

This repository contains templates and reusable workflow instructions only.
Do not commit real resumes, contact details, visa documents, application
history, browser sessions, authentication codes, or other personal data.

See `skills/jobhuntbot/references/safety-and-boundaries.md` for the complete
safety rules.
